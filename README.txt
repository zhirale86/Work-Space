ДОКУМЕНТООБОРОТ UTECH
=====================

Внутренняя система согласования документов, приказов и поручений
с интеграцией со сделками Битрикс24. Тестовая модель по техническому
заданию docs/01-tz.docx.


ЗАПУСК НА СВОЁМ КОМПЬЮТЕРЕ (WINDOWS)
------------------------------------

Шаг 1. Установите программы (один раз)

  - Node.js 22 LTS: https://nodejs.org — установщик Windows (.msi),
    все параметры по умолчанию.
  - PostgreSQL 16: https://www.postgresql.org/download/windows/ —
    установщик EDB. При установке задайте пароль пользователя postgres
    и запомните его; порт оставьте 5432.

Шаг 2. Распакуйте архив

  Например, в C:\docflow-utech — внутри будут папки server, web, docs.

Шаг 3. Создайте базу данных

  Пуск → «SQL Shell (psql)». На все вопросы нажимайте Enter, в конце
  введите пароль postgres из шага 1. Затем выполните две команды:

    CREATE USER docflow WITH PASSWORD 'docflow';
    CREATE DATABASE docflow OWNER docflow;

  Закройте окно командой \q

Шаг 4. Соберите интерфейс

  Откройте «Командную строку» (Пуск → cmd) и выполните по очереди:

    cd C:\docflow-utech\web
    npm ci
    npm run build

Шаг 5. Подготовьте сервер

  В той же командной строке:

    cd C:\docflow-utech\server
    copy .env.example .env
    npm ci
    npm run build
    npm run migrate
    npm run seed

  migrate создаёт таблицы, seed — тестовых сотрудников, сделки
  и демонстрационные документы.

Шаг 6. Запустите

    npm start

  Откройте в браузере http://localhost:3000
  Вход: ivanov, пароль Test12345!

  Окно командной строки не закрывайте — это и есть работающий сервер.
  Остановить: Ctrl+C. Следующие запуски — только шаг 6:

    cd C:\docflow-utech\server
    npm start

ЕСЛИ ЧТО-ТО НЕ ПОЛУЧИЛОСЬ
-------------------------

  «npm» не является командой
      Node.js не установлен или окно cmd открыто до установки —
      откройте новое окно.

  ECONNREFUSED 127.0.0.1:5432 / password authentication failed
      PostgreSQL не запущен либо не выполнен шаг 3. Проверьте службу
      postgresql-x64-16 (Пуск → «Службы»). Если вы поставили другой
      порт, исправьте его в строке DATABASE_URL файла server\.env.

  EADDRINUSE :3000
      Порт занят. Впишите в server\.env строку PORT=3100 и откройте
      http://localhost:3100 (также измените PUBLIC_URL).

  Начать с чистыми данными
      В SQL Shell: DROP DATABASE docflow; CREATE DATABASE docflow
      OWNER docflow; затем снова npm run migrate и npm run seed.

На macOS и Linux шаги те же: PostgreSQL — через Homebrew или пакет
дистрибутива, вместо copy — cp, пути — с прямой косой чертой.

Интеграция с Битрикс24 по умолчанию работает через встроенный эмулятор:
согласование видно в сделке на странице эмулятора. Подключение к
настоящему порталу — docs/06-admin-guide.docx, установка на сервер
компании через Docker — deploy/README.docx.
